免費與付費方案規則

二、免費方案 (Free Tier) 特點

  • 完全免費使用：只需一般的 Google 帳號即可建立專案並申請 API Key，不用輸入信用卡資訊。
  • 使用量限制：設有速率限制（如每分鐘請求數 RPM、每分鐘 Token 數 TPM、每日請求數 RPD），配額依專案層級計算。
  • 資料隱私條款：在免費方案下，輸入的 Prompt 與輸出回應會被 Google 用於改善產品與訓練模型。若需要企業級資料隱私（不被用於訓練），需綁定帳單升級至付費層級。

三、僅限付費方案 (Paid Tier) 的模型

包含高階/旗艦模型如 Gemini 4 Carbon、Gemini 4 Argon，以及 Nano Banana 圖像生成模型與 Lyria 音樂生成模型等，不提供免費試用額度。

四、Google TTS 主要功能特色

支援多種語言與繁體中文

可生成超過 70 種語言的語音，包含繁體中文與粵語。

多角色與 Podcast 模式

支援單一說話者以及多位說話者交替的對話模式，可製作類似 Podcast 的雙人或多角色語音。

語氣與標籤控制

透過提示詞或內嵌標籤（如語氣、節奏、暫停等調整）來控制說話風格。

多種音訊輸出格式

支援下載未壓縮的 WAV 檔案（預設 24 kHz 單聲道）、原始 PCM、Mu-law 或 A-law 等格式。

七、進階提示詞：Gemini Canva 強力提示詞

如果您需要更完整、帶有音訊處理等進階功能的 React 應用程式，請使用以下完整提示詞：

進階完整提示詞 (Prompt) 
使用以下模型 https://ai.google.dev/gemini-api/docs/models/gemini-2.5-flash-preview-tts?hl=zh-tw
創建react程式，輸入文字便能產出語音，透過呼叫 Gemini 的 TTS (Text-to-Speech) API 來串接語音合成功能，語音要台灣腔，具體實作方法如下：

1.使用專屬的模型端點：
程式碼中定義了 fetchGeminiAudio 函式來處理語音合成。它會向 gemini-2.5-flash-preview-tts 模型發送請求：   
JavaScript
const url = getGeminiApiUrl("gemini-2.5-flash-preview-tts");

2.建構請求 Payload：
在發送 API 請求時，會將要合成的台詞文字放入 contents，並在 generationConfig 中指定回傳格式為音訊 (responseModalities: ["AUDIO"])，同時透過 speechConfig 傳入指定的配音員名稱（voiceName）：   
JavaScript
const payload = {
contents: [{ parts: [{ text: speechText }] }],
generationConfig: {
responseModalities: ["AUDIO"],
speechConfig: {
voiceConfig: { prebuiltVoiceConfig: { voiceName: normalizedVoice } }
}
}
};

3.音訊資料處理與轉換：
Gemini API 會回傳 Base64 編碼的音訊資料。程式碼接收到資料後，會進行一連串的處理：   
- 將 Base64 字串轉換為位元組陣列 (base64ToUint8Array)。   
- 透過 resamplePCM 函式處理音調（Pitch）的變更，重新取樣 PCM 資料。   
- 最後使用 pcmToWav 函式將 PCM 資料加上 WAV 標頭，並轉換成瀏覽器可直接播放的 Blob URL (URL.createObjectURL)。   
JavaScript
const pcmBytes = base64ToUint8Array(inlineData.data);
const processedBytes = resamplePCM(pcmBytes, safePitch);
const objectUrl = pcmToWav(processedBytes, rate);

4.快取與播放：
處理好的音訊資料（包含 PCM 和 WAV URL）會被存入 audioCache.current 快取中，後續播放時（例如 playLine 函式）就直接將該 URL 餵給 HTML5 的 Audio 元素來播放。如果是多句連續播放或匯出，還會進一步將所有音效和語音的 PCM 資料在前端進行混音 (composeMixedFullAudio)。   

5.要在gemini中執行要強調：
環境自動注入 (Auto-Injection)：當在 Canvas 環境中執行這段程式碼時，Canvas 會監聽所有發送出去的 fetch 請求。當它偵測到目標是 generativelanguage.googleapis.com 且 key= 為空時，平台會自動在底層補上當前登入帳號的內部驗證 Token，然後再把請求送到 Google 伺服器。這種設計是為了讓開發者能在沙盒環境中安全地分享、測試程式碼，而不需要把真實的 API Key 寫死在程式碼中。
